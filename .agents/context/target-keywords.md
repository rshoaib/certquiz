## Post structure (for new exam guides)

Every cert exam guide should cover:
1. Exam code + version + date released
2. Cost + duration + question count + passing score (verify from vendor's official page)
3. Domains / objectives breakdown (table)
4. Recommended prep timeline
5. Practice resources (call out this site's free engine)
6. What changed from the previous version

## 🚫 What NOT to publish

- Exam dumps. The engine is a practice tool; never reproduce official exam questions.
- Marketing claims ("guaranteed pass"). Always honest.
- Outdated exam codes. Always check whether the vendor has released a new version.

## 📝 Anchor-text bank

When linking cross-cert: use the exam code (e.g., "AZ-900", "SAA-C03"), NOT "click here".
